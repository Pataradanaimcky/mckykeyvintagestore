# Sound organizer (/studio, menu "จัดเรียงเสียง")

People make and edit sounds on their own keyboard as usual. This page is only for putting those sounds in the order they want to find them: drag and drop on a big screen instead of moving one slot at a time on the keyboard. Sound editing and part settings do not belong here (owner decision 2026-11-12).

Order of work set by the owner: DX7 first (to learn the whole loop on a fully documented format), then MODX M, then FANTOM-0.

## What each keyboard does today

- DX7 (works end to end): open one or more .syx files (32-voice cartridges or single voices); the first 32 voices fill the cartridge, the rest wait in the pool. Drag or tap to reorder, rename (10 ASCII characters), listen through the site's FM engine (@audio/synth-dx7), then download the cartridge in the new order as a 32-voice .syx. Empty slots are saved as INIT VOICE. Packing is checked against the engine's unpack in tests/dx7.test.ts. Receive from the keyboard (2026-11-12): "รับเสียง 32 เสียงจาก DX7 ทาง USB-MIDI" listens on every MIDI input (Web MIDI with SysEx, Chrome or Edge) for a 32-voice bulk dump the owner starts on the DX7 itself (FUNCTION, button 8 MIDI until SYS INFO AVAIL, button 8 again, then YES at the transmit prompt; channel 1). The dump is checked (header, 4104 bytes, checksum, F7) before it becomes the cartridge; the old cartridge goes to the shelf. Nothing is sent to the keyboard: the DX7 manual's reception table lists no voice dump request, only one for DX1 performance data.
- MODX M Live Set (checked 2026-11-12; read-only "รับชื่อช่องจาก MODX M" added 2026-11-13, not tested on a real keyboard yet): names are printable ASCII only (MODX M Data List); USER banks 1–8, 16 pages each, 16 slots per page (Yamaha "Welcome to MODX M"). Bank Name and Page Name up to 20 characters; per slot Slot Name (20), Color from the keyboard's 16 names (Black, Red, Yellow, Green, Blue, Azure, Pink, Orange, Purple, Sakura, Cream, Lime, Aqua, Beige, Mint, Lilac), Volume and SSS Time (0.0sec–30sec, Hold, System; MODX M operation manual p. 361); edit jobs Copy, Exchange, Delete, Delete & Move; register with [SHIFT] + [LIVE SET]. Names, colors and jobs are from the MONTAGE M online manual's Live Set Edit page, which shares the Live Set system; confirm on a MODX M if anything differs. The chosen slot is outlined in orange, as on the keyboard.
- FANTOM-0 scenes (checked 2026-11-13): banks A–D of 128 scenes, A001–D128 (FANTOM-07 Reference Manual p. 28; MIDI Implementation bank select MSB 085, LSB 000 = A001–A128, 001 = B001–B128); SCENE SELECT shows 16 scenes as a 4 x 4 grid (Owner's Manual p. 17), so the organizer has 32 screens of 16, labelled A001–A016 … D113–D128. Scene Name is 16 characters of ASCII 32–127 (MIDI Implementation, Scene Common), so Thai and accented names are flagged like MODX M. Scene Write (Owner's Manual p. 22): [WRITE] → <SCENE> → <Rename> if needed → choose the number with [VALUE] or [DEC]/[INC] → <OK> → <OK>; the scene already at that number is overwritten. Paste scene names, arrange, follow the order sheet. Scene Chain (2026-11-13, Reference Manual pp. 74–77): the page and order sheet also give the chain steps and the order to register, so scenes can be played in the new order without overwriting any.

Work is kept in the visitor's browser per keyboard, in a downloaded work file, or in a share link. Nothing is uploaded.

## Preview sounds

- DX7: the real voice, through the site's FM engine.
- MODX M and FANTOM-0: the keyboards' own sounds are Yamaha/Roland samples and undocumented files, so they cannot play on the site. Each slot gets an open sample of the same type instead (Piano, E.Piano, Strings, Pad, Brass, Organ, Bass, Lead, Bell, Choir...), guessed from the name and changeable per slot. Samples: FluidR3_GM (CC BY 3.0) from midi-js-soundfonts, played by smplr (MIT), loaded from gleitz.github.io in the visitor's browser. Other open sample sets were not used because their licences could not be confirmed. Credit stays visible under the preview keyboard.
- Best match of all: the owner's own recordings of his packs, as audio demos.

## Demo banks

Every store pack opens as a demo bank on its keyboard (MODX M or FANTOM-0). Each slot plays the owner's recorded demo of that sound from `src/content/demos.ts` (first 8 seconds, through Web Audio, no file link), or a close-match preview until a recording exists. Demo banks can be played and rearranged but not downloaded, saved to a file or shared; the visitor's own work is kept aside and comes back with "กลับงานของฉัน".

## Where things live

- src/lib/studio/library.ts: keyboard targets (words, grid size, verified flag, sources), layout data, move/swap, fill, sort, order sheet, share links, import checks. Tests: tests/library.test.ts.
- src/lib/studio/modxm.ts: MODX M Live Set Slot Name requests and reply reading (read only). Tests: tests/modxm.test.ts.
- src/lib/studio/fantom.ts: FANTOM-0 Temporary Scene Name request (RQ1) and reply reading (DT1), used by the read-only button; Identity Request/Reply rules and `FantomPortFinder`, used by the button to find the FANTOM-0 port. Tests: tests/fantom.test.ts.
- src/lib/studio/dx7.ts: DX7 voice names, single-voice and cartridge .syx writing. Tests: tests/dx7.test.ts.
- src/components/studio/Organizer.tsx: the page.

## Rules

- Use each keyboard's own words, from the official manual, with the link in `sources`. Set `verified: true` only after checking.
- No maker logos, product photos or copies of a keyboard's screen design. Never ship factory sound data from any maker.
- Sending anything to a keyboard over USB that would overwrite its memory must be behind a clear confirmation, off by default, and labelled as needing a real-keyboard test.

## ทดสอบกับเครื่องจริง (ประมาณ 10 นาที)

สำหรับเจ้าของร้าน ทดสอบปุ่มรับข้อมูลทาง USB ทั้ง 3 ปุ่ม ทุกปุ่มอ่านอย่างเดียว ไม่เขียนอะไรลงเครื่อง ทำเฉพาะเครื่องที่มี

ก่อนเริ่ม: ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ เปิด /studio (เมนู "จัดเรียงเสียง") ต่อเครื่องก่อนเปิดหน้า เมื่อเบราว์เซอร์ถามเรื่อง MIDI / อุปกรณ์ MIDI ให้กดอนุญาต ปิดโปรแกรมเพลงอื่นที่อาจจับพอร์ต MIDI ไว้

### DX7 (ข้อ 1a)

1. ต่อสายอินเทอร์เฟซ USB-MIDI จากช่อง MIDI OUT ของ DX7 เข้าคอมพิวเตอร์ (DX7 ไม่มีช่อง USB)
2. บนหน้าเว็บ เลือกแท็บ DX7 กด "รับเสียง 32 เสียงจาก DX7 ทาง USB-MIDI" (หน้าเว็บจะรอ 2 นาที)
3. บน DX7 กด FUNCTION → ปุ่ม 8 (MIDI) จนจอขึ้น SYS INFO AVAIL → กดปุ่ม 8 อีกครั้ง → จอถามว่าจะส่ง → กด YES
4. ที่ควรเห็น: ตลับบนหน้าเว็บเปลี่ยนเป็น 32 ชื่อเรียงเหมือน INTERNAL 1–32 บนเครื่อง ตลับเดิมย้ายลงชั้นวาง กด ▶ ฟัง 2–3 เสียงเทียบกับเครื่อง
5. กด "ดาวน์โหลดตลับที่เรียงแล้ว (.syx)" แล้วลองเปิดไฟล์ใน Dexed หรือส่งกลับเข้า DX7 ด้วยโปรแกรมที่ใช้อยู่ (ถ้าสะดวก)

แจ้งกลับ: ข้อความบนจอ DX7 ตอนถามว่าจะส่ง (ตัวอักษรตรงตามจอ) · หน้าเว็บขึ้นข้อความอะไร · ชื่อครบ 32 และเรียงตรงไหม · เสียงที่ ▶ ใกล้เคียงไหม · ไฟล์เปิดใน Dexed/DX7 ได้ไหม

### MODX M (ข้อ 4f)

1. ต่อสาย USB จากช่อง USB TO HOST ของ MODX M เข้าคอมพิวเตอร์ บนเครื่องตั้ง MIDI IN/OUT เป็น USB ([UTILITY] → Settings → MIDI I/O) และ Device Number เป็น All หรือ 1 ([UTILITY] → Settings → Advanced) จดค่าที่ตั้งไว้เดิมทั้งสองอย่าง Bulk Receive (หน้าเดียวกัน) ปล่อยเป็น Protect ได้ หน้าเว็บไม่ส่ง Bulk Dump เข้าเครื่อง
2. บนเครื่องเปิด Live Set ที่มีชื่อช่องอยู่แล้ว จำเลขหน้า (Page) ที่เปิดอยู่
3. บนหน้าเว็บ เลือกแท็บ MODX M เปิดหน้าเลขเดียวกัน กด "รับชื่อช่องจาก MODX M ทาง USB (ยังไม่ได้ทดสอบกับเครื่องจริง)" → กด OK ในกล่องยืนยัน → รอประมาณ 8 วินาที
4. ที่ควรเห็น: 16 ช่องของหน้านั้นมีชื่อตรงกับบนเครื่อง ช่องเดิมบนหน้าเว็บย้ายลงชั้นวาง
5. ลองครั้งที่ 2: บนเครื่องเปลี่ยนไป Live Set Bank อื่น (หน้าเลขเดิม) แล้วกดอีกครั้ง

แจ้งกลับ: หน้าเว็บขึ้นข้อความอะไร (ได้กี่ช่อง กี่ช่องไม่ครบ) · ชื่อที่ได้ตรงกับ Bank ที่เปิดบนจอ หรือเป็นของ Bank อื่น · ครั้งที่ 2 ได้ชื่อของ Bank ใหม่ไหม · ชื่อตัวอักษรเพี้ยนหรือขาดไหม

### FANTOM-0 (ข้อ 5e, 5h)

1. ต่อสาย USB จากช่อง USB COMPUTER ของ FANTOM-0 เข้าคอมพิวเตอร์ บนเครื่องเปิด Receive Exclusive (หน้า SYSTEM: MIDI) และจดค่า Device ID ที่เห็น
   ถ้าคอมพิวเตอร์ไม่เห็น FANTOM-0: ดู [MENU] → SYSTEM → GENERAL → USB Driver (VENDOR ต้องติดตั้งไดรเวอร์จากเว็บ Roland, GENERIC ใช้ไดรเวอร์ของคอมพิวเตอร์ ได้แค่ MIDI) เปลี่ยนแล้วกด [WRITE] และปิด-เปิดเครื่อง จดว่าตั้งค่าไหนอยู่ตอนแรก
2. บนเครื่องเปิด Scene ที่รู้ชื่อ
3. บนหน้าเว็บ เลือกแท็บ FANTOM-0 กด "รับชื่อ Scene ที่เปิดอยู่จาก FANTOM-0 ทาง USB (ยังไม่ได้ทดสอบกับเครื่องจริง)" → กด OK
4. ที่ควรเห็น: ชื่อ Scene บนจอไปอยู่ท้ายชั้นวาง ช่องที่จัดไว้ไม่เปลี่ยน และ Scene บนเครื่องไม่เปลี่ยน
5. เปลี่ยน Scene บนเครื่องแล้วกดอีกครั้ง ควรได้ชื่อ Scene ใหม่
6. ลองครั้งที่ 3: ปิด Receive Exclusive แล้วกดอีกครั้ง (คาดว่าจะไม่ได้ชื่อ) แล้วเปิดกลับคืน

แจ้งกลับ: หน้าเว็บขึ้นข้อความอะไรแต่ละครั้ง · ชื่อตรงกับบนจอไหม · ค่าเริ่มต้นของ Receive Exclusive (เปิดหรือปิดอยู่ตอนแรก) · ชื่อและช่วงค่าของ Device ID ที่จอแสดง · ชื่อพอร์ต FANTOM ที่คอมพิวเตอร์เห็น (ถ้าดูได้) · รุ่น 06, 07 หรือ 08

ที่มาของชื่อช่องต่อ: MODX M "[USB TO HOST]" (MODX M6 Operation Manual p. 63, สำเนา Kraft Music), FANTOM-0 "USB COMPUTER" (Roland Support, FANTOM-06/07/08 connecting to a computer) ขั้นตอนอื่นเป็นขั้นตอนเดียวกับข้อความบนหน้า /studio

ส่งผลให้ project manager agent หรือจดลงใต้ข้อ 1a, 4f, 5e, 5h ด้านล่าง ถ้าปุ่มไหนทำให้บนเครื่องเปลี่ยนอะไร ให้หยุดทดสอบและแจ้งทันที
