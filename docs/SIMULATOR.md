# MODX M and FANTOM-0 simulators

Owner request, 2026-11-16: the site has no MODX M or FANTOM simulator; he wants one, and if there is no ready-made one, a way must be found. A dedicated scheduled task, "Mcky keyboard simulator builder", builds it. The project manager ("Mcky project manager") sets its priorities in `docs/ROADMAP.md` (Next, items marked "simulator agent") and answers its questions like the other agents (AGENTS.md, "Who decides").

## What "simulator" means here (read first)

- **No exact copy is possible or allowed.** The real sounds are the makers' own samples and data (Yamaha AWM2 waveforms, Roland ZEN-Core PCM). They cannot be downloaded, extracted or redistributed, and there is no official browser version of either keyboard. Never ship, extract or reverse-engineer factory sounds, waveforms or firmware; never copy the panel or screen design (owner decision of 2026-11-12, MODX M entry in DESIGN_LOG).
- **What we can build:** a page in the home-page rack for each keyboard that works the way the keyboard works and is played with our own engines and openly licensed samples:
  - **MODX M style:** a Performance of up to 8 keyboard parts (layer and split by key range), sample, FM and analog-style engines like the keyboard's three engines, a Super Knob that moves several parameters at once, and 8 Scenes that recall part settings.
  - **FANTOM-0 style:** a Scene with zones (layer and split), tones made of partials (sample, analog-style, supersaw, noise), and 16 pads.
  - The face is the store's own drawing, as on /studio. Labels say plainly that it is an emulation and not the keyboard's real sound, for example "จำลองการทำงานแบบ MODX M · ไม่ใช่เสียงจริงของเครื่อง". Maker names are plain text only, as in the footer trademark note.
- **Why it sells packs:** players learn the workflow on the site, hear the store's own sounds built for the simulator, and buy the real packs for their keyboard. Simulator versions of the store's packs are the owner's to approve (Waiting on the owner).

## Owner request 2026-11-16 (second message): feel like the real keyboard, and connect to it

**Face.** The owner wants playing the simulator to feel like playing a real MODX M or FANTOM-0. Do this through *function and placement*, not by copying the look:
- Same controls, in the same places relative to each other, doing the same jobs, with the keyboard's own words on them. MODX M: part sliders and knobs, the Super Knob, Scene buttons, part select/mute/solo, a display showing what the keyboard's display shows (Performance name, parts, Scene). FANTOM-0: zone sliders and knobs, the pads, Scene select, zone on/off, a display with Scene and zones.
- The same steps to do things (e.g. pick a part, then turn its knobs; press a Scene button to recall). A player who knows the keyboard should know where to reach without reading.
- The appearance stays the store's own drawing (shapes, colors, type, no maker logos, no copy of the panel's styling or the screen's graphics), like /studio. Yamaha's and Roland's panel designs are theirs; the owner's earlier permission is not his to give (DESIGN_LOG, 2026-11-12). Copy the layout of controls and the workflow, never the styling.

**Connect to the real keyboard (Web MIDI, USB).** Works in Chrome and Edge (desktop and Android); say plainly on the page when the browser has no Web MIDI (e.g. Safari on iPhone). Only messages printed in the maker's own MIDI documentation (MODX M / MONTAGE M Data List and MIDI implementation; FANTOM-0 MIDI implementation). Add each message with its source page to this file before using it.
- **In (keyboard → site):** play the simulator from the real keyboard's keys, wheels, sustain and knobs/sliders (notes, pitch bend, CCs). Learn which CC each control sends from the manual, with a "learn" fallback (turn a control, the site picks it up).
- **Out (site → keyboard), live control only:** select a Performance / Scene on the real keyboard (Bank Select + Program Change as documented), send knob/slider CCs, all-notes-off. Nothing that writes or overwrites the keyboard's memory.
- **Writing to the keyboard's memory:** not part of the simulator. Only if the maker documents it, behind a clear confirmation that is off by default and says it is untested on a real keyboard (same rule as /studio).
- Everything is labelled "ยังไม่ได้ทดสอบกับเครื่องจริง" until the owner tries it on his keyboards (Waiting on the owner).

## Confirmed facts (with sources)

- MIDI in, read side (S8): only the general MIDI 1.0 channel messages are read: Note On (9n), Note Off (8n, or 9n with velocity 0), Control Change (Bn), Pitch Bend (En, 14 bits, 8192 = centre), sustain = CC 64; CC 0/32 (Bank Select) and 120–127 (channel mode) are not learnt. Source: MIDI Association, [Summary of MIDI 1.0 Messages](https://midi.org/summary-of-midi-1-0-messages) and [Control Change messages](https://midi.org/midi-1-0-control-change-messages). Nothing is sent to the keyboard.

- MODX M default Control Change numbers (S8c, read 2026-11-18). From the [MODX M Data List (Yamaha, data.yamaha.com)](https://data.yamaha.com/files/download/other_assets/9/2574209/MODX-M_data_list_En_B0.pdf). Page numbers are the nearest running labels in the PDF's text, so each may be off by one:
  - MIDI Parameter Change Table (SYSTEM), block System (about p. 226): "Super Knob Control Number", Off, 1–95, default 00 5F = **CC 95**; "Scene Select Control Number", Off, 1–95, default 00 5C = **CC 92**.
  - MIDI Data Format, (3-1-3) Control Change, note *4 "The default CONTROL NUMBERs of ASSIGNABLE CONTROLLER" (pp. 213–214): **ASSIGNABLE KNOB 1–8 = CC 17–24**, BREATH CONTROLLER 2, FOOT CONTROLLER 1 = 11, FOOT CONTROLLER 2 = Super Knob, RIBBON CONTROLLER 16, ASSIGNABLE FUNCTION 1 = 86, ASSIGNABLE FUNCTION 2 = 87, MOTION SEQ TRIGGER 89, FOOT SWITCH = Arp SW. Transmitted assignable range: 1..95.
  - [MODX M Operation Manual, Chinese edition (Yamaha)](https://data.yamaha.com/files/download/other_assets/9/2584709/MODX-M_operation_manual_Zh_C0.pdf) p. 371, [UTILITY] → Settings → MIDI I/O: Super Knob CC sets the number the Super Knob generates (Off, 1–95; at Off, SysEx is used). Scene CC sets the number generated when Scenes change (Off, 1–95); values select Scenes in blocks: 0–15 Scene 1, 16–31 Scene 2, 32–47 Scene 3, 48–63 Scene 4, 64–79 Scene 5, 80–95 Scene 6, 96–111 Scene 7, 112–127 Scene 8; if both numbers are the same, Scene CC wins and Super Knob CC is disabled. The English edition's link on usa.yamaha.com would not open; the [MONTAGE M online manual](https://manual.yamaha.com/mi/synth/montage_m/en/om02screenparameters0320.html) says the same in English for MONTAGE M.
  - Assign knob numbers can be changed per the [Control Number screen](https://manual.yamaha.com/mi/synth/montage_m/en/om02screenparameters0060.html) (MONTAGE M manual: Off, 1–95), so these are defaults only.
  - Unknown: any CC for the Control sliders. The parts of these documents read do not print one; the Data List's transmit list has Channel Volume (CC 7) but does not tie it to the sliders, so the page does not assume it. Nothing here is checked on a real keyboard.

- Part Note Limit and Velocity Limit (S1, read 2026-11-18). [MONTAGE M Operation Manual, Part Edit (AWM2), Part Settings](https://manual.yamaha.com/mi/synth/montage_m/en/om02screenparameters0080.html): "TG Vel Limit" sets the Part's velocity range, 1–127; "TG Note Limit" sets its note range, C−2 to G8. With the first value above the second the Part plays outside the gap: 93 to 34 plays 1–34 and 93–127; C5 to C4 plays C−2 to C4 and C5 to G8. The [Performance screen, Range view](https://manual.yamaha.com/mi/synth/montage_m/en/om02screenparameters0050.html) shows both per Part. The [MODX+ Reference Manual](https://data.yamaha.com/files/download/other_assets/4/1583934/modx_plus_en_rm_a0.pdf) p. 32 says the velocity view is "useful for setting Velocity split among Parts". These are MONTAGE M and MODX+ documents; the MODX M's own manual was not opened for this (the link needs a permission this run did not get), so that the MODX M behaves the same is unconfirmed.

- Part limits on the MODX M itself (S1b, read 2026-11-19 Bangkok). [MODX M Operation Manual, Japanese edition (Yamaha, jp.yamaha.com)](https://jp.yamaha.com/files/download/other_assets/9/2584699/MODX-M_operation_manual_Ja_A0.pdf), read as extracted text; the English copy on usa.yamaha.com would not open:
  - p. 19: hold [SHIFT] and press [SPLIT]: the Performance screen's **Part - Note** view appears; change each Part's note range with keyboard input, the data dial and so on. [SPLIT] alone opens the **Split Job** screen (split points and groups; [EXIT] or Done confirms, [×] cancels).
  - p. 75, Performance screen, Display Mode Range: **Note Limit** sets the lowest and highest note that sound the Part, C−2 to G8. With the lowest above the highest, as C5 to C4, it sounds in two ranges; the manual prints them as C−2 to C4 and C5 to C8 (C8 as printed, while the range ends at G8 and the MONTAGE M manual says G8; the page plays up to G8). **Velocity Limit** sets the velocity range, 1 to 127; this page does not say what a first value above the second does, so that rule still rests on the MONTAGE M manual (see the Part Note Limit entry above).
  - pp. 80, 83: View Mode includes **Velocity - Note** ("useful for setting velocity splits between Parts") and **Part - Note**; both are switched with the display knob. What these views draw is not described, and the page does not copy them: it is a plain list in the store's style.
  - Unknown: the order of keys in keyboard input for Part - Note. "Keyboard" on in a context menu, then pressing keys, is printed only for Pattern Edit (pp. 117–118). The page's KEYBOARD button and its one-key-per-selected-value step are the store's reading. Whether Scenes hold these limits is also not read; on the page they do not.

- Split Job on the MODX M (S1c, read 2026-11-19 Bangkok). [MODX M Operation Manual, Chinese edition (Yamaha)](https://data.yamaha.com/files/download/other_assets/9/2584709/MODX-M_operation_manual_Zh_C0.pdf):
  - p. 19: [SPLIT] opens the Performance's Split Job screen. The keyboard is divided into groups and a Part is assigned to each; two or more Parts in one group layer. Tap the screen's items to set the number and position of the Split Points; [SHIFT] + a group button puts one Part in several groups; [EXIT] or Done confirms; × at the top left cancels.
  - p. 389: **Split Points** Off, 1–3. **Split Point 1–3** C#−2 to G8; with Keyboard On the point can be set from the keyboard. **Part Name**: menu with Category Search and Delete. **[+]** adds a Part. **Group A–D**: the button assigns the Part. **×** cancels the group assignment. **Done** confirms and closes. The top-left × closes without confirming, except for adding, deleting or changing Parts.
  - The [MONTAGE M online manual, Split Job](https://manual.yamaha.com/mi/synth/montage_m/en/om02screenparameters0350.html) and its [PDF](https://data.yamaha.com/files/download/other_assets/2/2172442/MONTAGE-M_operation_manual_En_v300_K0.pdf) pp. 29, 510–511 say the same, with Split Points 1–3 (no Off).
  - **Unknown from Yamaha:** what Split Points Off does; which keys each Group plays; which side the Split Point key belongs to; whether the job writes each Part's Note Limit. The manual's screen picture could not be viewed (only the text opens here).
  - Not official: a member of [Yamaha's Synth Forum](https://yamahasynth.com/community/modx-series-synthesizers/modx-m7-set-different-octaves-on-split-keyboard/) (Pete, 2026-06-13, not shown as Yamaha staff) writes that A starts at C−2, D ends at G8, the regions touch and every region has a key, a Split Point is the **end** key of its region, and a Part in B and D also gets C. The end-key claim does not fit Yamaha's printed range: a point at G8 would leave nothing above it, while a point as the **lowest key of the next Group** gives every printed value (C#−2 to G8) at least one key on each side. The page uses that second reading, shown on screen as the store's reading; the owner's test settles it (question in ROADMAP).

## ทดสอบกับเครื่องจริง (ประมาณ 10 นาที)

สำหรับเจ้าของร้าน (ข้อ S11) ทดสอบการเล่นหน้า MODX M และ FANTOM-0 จากคีย์บอร์ดจริงทาง USB หน้าเว็บรับข้อมูลอย่างเดียว ไม่ส่งอะไรเข้าเครื่อง ไม่เปลี่ยน Performance / Scene บนเครื่อง ทำเฉพาะเครื่องที่มี

ก่อนเริ่ม: ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ ต่อสาย USB ก่อนเปิดหน้า ปิดโปรแกรมเพลงอื่นที่อาจจับพอร์ต MIDI ไว้ ลดเสียงของคีย์บอร์ดเองลง (เสียงเครื่องจะดังพร้อมเสียงจากหน้าเว็บ) เปิดหน้าแรก แล้วไปที่แร็ค แท็บ MODX M (`/#play-modxm`) หรือ FANTOM-0 (`/#play-fantom`) คลิกคีย์บนจอหนึ่งครั้งก่อน เพื่อให้เบราว์เซอร์เปิดเสียง

### MODX M

1. ต่อสาย USB จากช่อง [USB TO HOST] ของ MODX M เข้าคอมพิวเตอร์ บนเครื่องตั้ง MIDI IN/OUT เป็น USB ([UTILITY] → Settings → MIDI I/O) จดค่าเดิมไว้
2. บนหน้าเว็บกด "ต่อคีย์บอร์ด USB" เมื่อเบราว์เซอร์ถามเรื่อง MIDI ให้กดอนุญาต ควรขึ้น "ต่อแล้ว" พร้อมชื่อพอร์ต
3. เล่นโน้ตเบาและแรงบนเครื่อง: หน้าเว็บควรมีเสียง และเบา/แรงตามที่กด เหยียบ sustain แล้วปล่อย: เสียงควรค้างแล้วหยุด
4. กด PART 1 บนหน้าเว็บ กด LEARN ข้างหัวข้อ PART LEVEL แล้วเลื่อน Control slider 1 บนเครื่อง: fader บนหน้าเว็บควรขยับตาม และขึ้นเลข CC
5. กด LEARN ใต้ Super Knob บนหน้าเว็บ แล้วหมุน Super Knob บนเครื่อง: Super Knob บนหน้าเว็บควรขยับตาม ถ้าไม่ขยับ ลองหมุน Knob 1 แทน แล้วจดว่าอันไหนใช้ได้
6. กดค้างโน้ตหนึ่งตัวแล้วหมุน pitch bend wheel ขึ้นลง: เสียง Pad (ส่วน AN-X) บนหน้าเว็บควรเพี้ยนขึ้นลงได้ราว 2 เสียง (±2 semitones) แล้วกลับตรงเมื่อปล่อย เสียงเปียโน (ส่วนแซมเปิล) ยังไม่ bend ตอนนี้ถือว่าปกติ (ข้อ S8e)
7. กด "ใช้เลข CC ตามเอกสาร Yamaha" แล้วหมุน Super Knob บนเครื่อง: Super Knob บนหน้าเว็บควรขยับตาม (CC 95) จากนั้นกดปุ่ม SCENE 1–8 บนเครื่อง: Scene บนหน้าเว็บควรเปลี่ยนตาม (CC 92) ถ้าไม่ตาม ดูเลขที่ [UTILITY] → Settings → MIDI I/O (Super Knob CC, Scene CC) อย่าแก้ค่า แค่จดไว้

## Performance budget (S7, measured 2026-11-18)

How it was measured: production build, Chromium 157 at 390 × 844 on the agent's 2-core cloud machine, all 8 Performances and all 8 Scenes, 6 keys held while a fader moves. **Not a real phone.** The sample host cannot be reached from the sandbox, so sample parts played a synthetic stand-in bank (88 notes); real download and decode times are unknown.

| Budget (store presets; `tests/sim-budget.test.ts` enforces the first three) | Limit | Heaviest now |
|---|---|---|
| Channels per Performance / Scene | 5 | 5 (FANTOM-0 Scenes) |
| FM-X parts per Performance | 1 | 1 |
| AN-X / VA / FM-X parts per Performance / Scene | 4 | 4 (MCKY Supersaw Stack) |
| Voices per AN-X / VA part, per FM-X part | 6, 6 | code limits, unchanged |
| Partial channels a Scene may load (code limit) | 8 | 5 used |
| Audio work, 6 notes held (share of real time on this machine) | under 15% | 9.7% MCKY EP & Strings; 8.2% MCKY Sweep Pad; 6.5% MCKY Supersaw Stack |
| Audio work, 16 notes held | under 15% | 11.3% MCKY Sweep Pad; 10.7% MCKY EP & Strings |

The 15% lines are the store's own rule of thumb, not a measured phone limit. Sample voices have no count limit in smplr; 48 voices at once (16 notes, three layers) stayed inside the numbers above.

Results at 390px, with Chrome's CPU throttling at 1×, 4× and 6×:

| | 1× | 4× | 6× |
|---|---|---|---|
| Key press to READY, slowest MODX M Performance | 0.5 s | 1.1 s | 1.5 s |
| Key press to READY, slowest FANTOM-0 Scene | 1.2 s | 1.8 s | 2.5 s |
| Frame time while playing, 95th percentile | 17 ms | 17 ms | 17 ms |
| Slowest frame while playing | 33 ms | 33 ms | 50 ms |
| Key press to the key lighting, slowest | 33 ms | 46 ms | 55 ms |
| Long tasks while playing | 0 | 0 | 0 |
| Audio underruns (`AudioContext.playbackStats`) | 0 | 0 | 0 |

No sideways scroll, no console errors, and the rack stayed on the right page on both simulators.

Limits of this check:
- **CPU throttling slows the page's main thread, not the audio thread.** The same worklet loop took 1.59 ms at 1× and 1.70 ms at 6×, so the underrun row above says nothing about a slow phone by itself.
- To load the audio thread, an extra worklet burned time in each 2.9 ms audio block on the three heaviest presets. With 1.8 ms extra: 0 underruns on all three, with 6 keys held. With 3.2 ms extra (more than the block itself): 326–383 underruns in 4 seconds, which shows the counter does detect dropouts. So these presets keep working with the audio thread doing roughly 7× its normal work (MCKY EP & Strings: 0.28 ms normal, about 2.1 ms in total). How a given phone compares with this machine is unknown (S7c).
- Output latency on phones is unknown: it depends on the device and is not visible here.
