รุ่นที่ใช้ได้

รุ่นใช้ได้ไหมหมายเหตุ
MODX M6 / M7 / M8ใช้ได้โหลดเป็น Library ได้เลย
MONTAGE M6 / M7 / M8xใช้ได้โหลดเป็น Library ได้เลย
ปลั๊กอิน ESPใช้ได้เปิดบนคอมพิวเตอร์
MODX / MODX+ รุ่นเดิมใช้ไม่ได้ไฟล์คนละรูปแบบ (.X8L)
ใช้เวลาไม่ถึง 5 นาที

วิธีติดตั้ง

  1. ดาวน์โหลดไฟล์ .Y2L จากอีเมลยืนยันการสั่งซื้อ แล้วคัดลอกลง USB แฟลชไดรฟ์
  2. เสียบ USB ที่เครื่อง กด UTILITY แล้วเลือก Contents → Load
  3. ตั้ง Content Type เป็น Library File แล้วแตะชื่อไฟล์
  4. เปิด Category Search แล้วเลือก Bank เป็นชื่อแพ็กเพื่อเรียกเสียง

โหลดแล้วเสียงเดิมในเครื่องหายไหม

ไม่หาย แพ็กติดตั้งเป็น Library แยกจากเสียงโรงงานและเสียง User ของคุณ

ใช้เสียงนี้อัดเพลงหรือเล่นงานจ้างได้ไหม

ได้ ใช้ในงานเพลงและงานแสดงของคุณได้เต็มที่ แต่ห้ามนำไฟล์แพ็กไปแจกหรือขายต่อ
